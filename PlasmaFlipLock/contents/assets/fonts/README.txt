PlasmaFlipLock digit font
=========================

BebasNeue-Regular.ttf — Bebas Neue, © 2010 Dharma Type.
License: SIL Open Font License 1.1 (see OFL.txt in this folder).
Bundled unmodified from the Google Fonts repository. OFL permits this usage.

Used for the flip-clock digits (tall condensed numerals). Loaded at runtime
by the FontLoader in contents/LockScreenUi.qml; if the file is missing or
unreadable, PlasmaFlipLock automatically falls back to installed fonts
(Bebas Neue → Oswald → Barlow Condensed → Roboto Condensed → Noto Sans).

To use a different digit font, drop a .ttf/.otf here and adjust the
FontLoader source (contents/LockScreenUi.qml) + Theme.digitFontFamily.
